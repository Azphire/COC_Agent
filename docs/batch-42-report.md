## 分发与权限

主机在准备包界面查看要求，在角色编辑器选择 HO、预览并明确核准，再发布冻结卡到房间；通过正常房间界面把 HO 分配给卡当前对应成员。角色方案与房间准备版本/来源定义不一致时拒绝分发。

房间绑定时冻结 HO 目录，分发记录保存在原 session state 中并随原存档恢复。事件保留实际主机 actor，另有显式 recipient 和 `recipient_and_host` 可见性；HTTP、WebSocket实时广播/重放、JSONL/Markdown导出使用相同过滤。其他成员既看不到目录，也看不到别人卡内的私密定义。含 HO 的角色禁止普通成员自行抢领，正式分发前本人卡也不带 HO 原文。

本人 AI 的 `private_handouts` 固定包含本人完整文本，不依赖最近事件窗口。KP 默认载入当前行动者 HO，另有私密目录，可用既有角色读取工具查看其他 HO；完整来源留在持久记录中，避免重复块 ID 挤占模型预算。公开旁白不接收 HO。接收者锁保留在追加日志中，读档不能把已披露秘密重新分配给另一个人；分发前存档恢复后重试相同请求会恢复原分发并产生定向恢复事件，不重复加值。
