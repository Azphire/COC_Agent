## 实现与边界

- 摘要正文绑定来源记录和字段/原文片段，实际可用正文从原记录渲染；生成的自由摘要留在审计，不凭正确的`required_facts`副本为错误正文背书。旧段读取时生成安全投影，原存储不重写，不新增LLM复核。
- 任务按请求、执行者、目标/接收者、物品实例、操作数量及实际回执结算；检定通过不代替操作完成，剩余项保留。不同物品、接收者、数量的交接不因同为`give`互相替换。
- 召回接通当前场景、公开实体ID/别名、近期有据指代与任务关联。旧场景证据仍可召回，带历史属性，不能由此获得当前操作权限。必要精确事实/任务优先；段和原文按来源范围/hash去重，未被段正文覆盖的长原文尾部保留。
- 当前原话、多个问题和格式要求保留至规划、`response_brief`及最终messages；公开旁白只保留KP的`speaking_style`，不传完整私密profile，不强制固定句数。明确对象被改为无关可见对象时拒绝误操作。
- 缓存稳定schema转换和保守计量。当前环境没有可直接使用的Qwen匹配tokenizer，仍标记`conservative_estimate`，实际usage另记；默认及显式容量、模型配置不变。
