### 职业分组

教授、图书馆管理员、医生按本地原文保留学术／个人专业白名单，接入已允许方向的自定义外语、艺术／手艺、科学及受限学问。不同科学专业可以各占一个名额；驾驶、生存、格斗、射击不进入该受限学术组。

分组只增加`distinct_directions`配置：默认true保留罪犯、士兵等混合方向约束；原文明示同类多个专业的组配置false。任意组仍有神话禁购、年代和KP引入约束。同ID在固定项、组内、跨组重复占位均拒绝，没有将所有组改成任意技能。

### 三类专业与KP引入

驾驶基础1、生存基础10、学问基础1，来自服务端模板；玩家只填名称。复用既有稳定ID、同类别重名检测、两类点池、99上限、改名保留投入、删除撤回分配、导入重算及冻结流程。格斗／射击继续使用原目录。

规则书明确驾驶和生存可购买具体专业。1920年代飞行器有限制；已知现代飞行器名称由服务端拦截，其余自由名称的年代／背景由KP核对。学问是须由KP决定引入的特殊知识；目录学问同样受限，未引入者不会以基础值自动成为运行时技能。不能用同名“克苏鲁神话”绕过禁购，不授予神话、法术或修改SAN。

主机车卡编辑器在首次保存后显示待引入项，勾选并保存后才能最终确认。核准绑定版本、ID、名称和年代；改名保留点数但使旧核准失效。外部导入清除核准，不能携带伪造许可。房间提交允许仅有待KP引入问题的卡，主机接受时明确核准界面列出的专业，再调用原确认及事务发布／分配服务；其他错误继续阻断。

同步了车卡、角色提交预览、运行时显示、KP候选、`inspect_character`的六类名称与技能值。前端角色提交面板复用既有专业显示函数。检定／上下文查找按快照的精确规则版本缓存不可变配置，避免扩大目录后在每次查找中重复解析YAML。
