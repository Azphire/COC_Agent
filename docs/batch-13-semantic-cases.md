# 第十三批语义用例

由第十二批失败对话归纳。Fake 只验证给定规划后的状态与权限；真实模型需要自行理解原话。验收不匹配固定台词。

| 类别 | 说法或场景变化 | 行为与事实标准 |
|---|---|---|
| 问过去声音 | 问管理员昨晚的钟声；问车厢乘客停车前的响动 | 回答者是被问的人；不让玩家现在聆听；未记载见闻允许不清楚 |
| 阅读明显文字 | 压平公告读正面；走近交接簿读记录；辨读车厢标牌 | 可见文字不自动叫侦查；隐藏夹页、隐蔽物件另按实际条件裁决；原文未记载内容不补写 |
| 询问归还 | 你要先拿回手电吗；雨伞还需要用吗；要不要现在还工具 | NPC可表达意愿；物品没有因此完成交接，玩家仍决定递出 |
| 自然撤回 | 不掷了先听他说完；算了暂时不试，先问她；放下这事换个办法 | 规划理解撤回及同句问题；服务端仅取消自己未掷自愿尝试，固定骰和SAN不可撤销 |
| 一句两种目标 | 问小禾同时照门边；向程叔发问同时翻地图；问队友同时查看楼梯 | 谈话对象与动作目标分开；建议和条件句不写成动作 |
| 队友后续 | 直接问队友，再请其查看纸背；队友实际尝试后KP续讲 | 问题交给队友；行动走自己的KP回合；叙述使用其触发消息与真实结果，不能复用旧撤回句 |

合理检定的正例：争取不愿合作的人信任、检查模组明确需要侦查的隐蔽物件、已有危险情境下移动。玩家建议技能可以被考虑，不能反过来制造障碍。
