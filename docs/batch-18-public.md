# 第十八批公开流程摘录

本页仅摘要最终C45房间 `final-v8`（`4cae89f4-59ee-4e63-9551-38fcf711fce5`）实际发生的公开主线。完整公开事件在本地 `final-v8/PUBLIC.md` 与 `PUBLIC-events.json`；检定细节只在有权查看的玩家及主机记录中保留。

周岚和沈砚从6号车厢醒来，沿5号进入4号。受伤乘务员实际告知：“驾驶室钥匙...在黑包里。黑包掉在3号车厢前门附近。你得去那里找。”周岚替他止血包扎，急救成功。

两人进入3号。周岚翻找前门附近的黑包，侦查经普通规则结算后取得两把钥匙，再交给沈砚。调查板显示钥匙持有者已变更。

在2号车厢，周岚打开手机灯和持续铃声，并观察喘息来源。灯只能照亮近处，系统先询问靠近还是留在原处。保存重启后，这个问题仍在；周岚选择靠近，随后公开观察明确看清了非人形态，并完成SAN。重复同一回答没有再扣理智。

周岚实际将仍在响铃的手机扔到旁边座椅下。撞击吸引了循声者，手机留在2号并持续响铃，两人趁机进入先头车厢、关上通往2号的门。沈砚用自己持有的钥匙实际打开驾驶室和控制面板。

周岚请求沈砚减速停车；仍持钥匙的沈砚随后实际操作了减速杆。两人经历黑暗、咀嚼声和醒来后的恐惧。B结局对应的SAN按实际经历者逐人完成，保存重启后再确认终幕。公开回执确认B结局，奖励只结算一次；再次保存恢复后资源和奖励一致。
