|本批新增实测阻断：拉杆没有匹配操作|公开方法标题可能包含“说明”等描述词；在本地、已公开、操作能力匹配的候选中解析实际对象，只有唯一候选才修复目标，再交由既有 KP 方法选择和权限校验。|
